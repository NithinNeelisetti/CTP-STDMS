How the algorithm works

  1. Build a directed graph from prerequisite tasks to dependent tasks.
  2. Use Kahn's topological-sort algorithm to find tasks whose prerequisites are satisfied.
  3. Put eligible tasks into a heap ordered by priority, deadline, and task ID.
  4. Repeatedly choose the highest-ranked eligible task and release its dependent tasks.
  5. If not all tasks can be scheduled, report a dependency cycle.

Complexity: O((V + E) log V), where V is the number of tasks and E is the number of dependency links.
